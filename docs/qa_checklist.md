# MVP-0 QA Checklist

更新时间：2026-07-16

## 功能验收

- [x] 页面可在本地开发服务器运行。
- [x] 玩家和对手初始完整度均为 10。
- [x] 每回合展示 3 张不重复卡牌。
- [x] 卡牌池基准版本包含 6 张卡牌。
- [x] 每回合只能结算一次选择。
- [x] 卡牌效果、对手回应和临时加成按规定顺序结算。
- [x] 回合最多推进至第 5 回合。
- [x] 对手归零时显示胜利并停止对手回应。
- [x] 玩家归零或五回合未取胜时显示失败。
- [x] 游戏结束后卡牌不可继续点击。
- [x] 重新开始会重置完整度、回合、状态、临时加成和手牌。
- [x] TypeScript 类型检查和 production build 通过。
- [x] 100 个固定随机种子的模拟对局均保持合法状态，并在五回合内结束。

## 开发者入场测试

- [ ] Test 1：Leader 亲自修改卡牌名称、数值和描述。
- [ ] Test 2：Leader 亲自增加第七张卡并说明修改文件。
- [x] Test 3：已记录并修复真实 BUG-001 与 BUG-002，回归构建和云端部署通过。
- [ ] Test 4：Leader 亲自完成 Git commit、查看改动、回退和恢复。
- [x] Test 5a：取得公开浏览器 URL，并在发布设备完成线上交互验收。
- [ ] Test 5b：Leader 在另一台设备打开公开 URL 并运行一局。

公开地址：https://ireian.github.io/three-minute-debate-mvp0/

未勾选的 Leader 测试不能由 Codex 代替通过。Codex 可以准备练习分支和逐步提示，但最终操作与解释必须由 Leader 完成。

## Scope 验收

- [x] 单页面、单场景、单对手。
- [x] 无地图、剧情、遗物、永久成长、存档、账户或后端。
- [x] 无音乐、正式美术或付费素材。
- [x] 无生产运行时依赖；仅使用 TypeScript、Vite 和 Vitest 开发依赖。
- [x] 未开始正式 Roguelite MVP。

## 已知限制

- 目前只有占位视觉和文字反馈。
- 没有数据分析后端，符合 MVP-0 scope。
- Chrome 扩展偶尔记录消息通道错误；项目本身不使用扩展消息或异步消息通道，未观察到游戏功能影响。
